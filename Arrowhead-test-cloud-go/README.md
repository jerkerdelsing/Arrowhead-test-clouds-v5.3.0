# Arrowhead v5.3.0 Go test cloud

A local Docker Compose deployment of an Eclipse Arrowhead 5.3.0 local cloud in which every core and support system is
the Go implementation, built from the primary source tree `Eclipse-Arrowhead-go`. It is one of three v5.3.0 test
clouds in this repository; the Java cloud is in `../Arrowhead-test-cloud-java`, the Rust cloud in
`../Arrowhead-test-cloud-rust`.

| | |
|---|---|
| Cloud | `GoCloud.Company.arrowhead.eu`, with its own cloud CA |
| Compose project | `arrowhead-v53-test-cloud-go` (27 services) |
| Compose file | `compose.yaml`, generated by `v530/generate.py` from `v530/base-compose.json` |
| Images | `arrowhead-go-v530/*:20261111-v530`, built by `v530/build.sh`; RabbitMQ, Mosquitto and nginx are pinned upstream images |
| Host ports | loopback only, 74xx (see below) |
| Console | http://gocloud-v53.localhost:7490/ |
| Federation | off: no relay, neighbour clouds or organisation PKI |

`v530/README.md` is the deployment record: where each file came from, what differs from the 5.2 GoCloud, the test
results and the known gaps.

## Systems and ports

Every port is published on `127.0.0.1` only. A host port is the system's default 84xx port minus 1000; containers talk
to each other on the defaults. All system APIs require mutual TLS with a certificate of the cloud CA.

|---|---|---|---|---|
| ServiceRegistry | 7443 | | DataManager | 7461 |
| Authentication | 7444 | | TimeManager | 7463 |
| ConsumerAuthorization | 7445 | | Blacklist | 7464 |
| DynamicServiceOrchestration | 7441 | | TranslationManager | 7465 |

| PlantDescriptionEngine | 7432 | | DeviceQoSEvaluator | 7472 |

LocalCloudManager and its `docker-proxy` publish no host port: the console is reached through `console-proxy`, and
the Docker socket is held only by the whitelisting proxy.

## Prerequisites

- Docker with Compose v2, `python3` with PyYAML, `jq`, `openssl`.
- macOS: `scripts/init.sh` stores the console password in the keychain.
- The primary Go source checked out next to this repository, as `v530/build.sh` expects:

  ```
  <parent>/
    Eclipse-Arrowhead-go/                              primary source
    Arrowhead-test-clouds/Arrowhead-test-cloud-go/     this folder
  ```

- `v530/generate.py` builds the compose file from `v530/base-compose.json`, which holds absolute paths of the machine
  it was recorded on. Adjust `OLD_ROOT` in `generate.py` and those paths when deploying elsewhere.

## What is not in git

Credentials are generated per installation and are excluded by `.gitignore`: `.env`, `secrets/`, `security/x509/`,
`security/bundles/`, `security/bundles-go/`, `security/crl/`, every `*.key` and `*.p12`, runtime state and logs. A
fresh clone therefore has no CA, certificates or passwords; the steps below create them. Never copy these folders
between clouds or hosts.

## Deploy

```sh
python3 v530/generate.py        # compose.yaml
./scripts/init.sh               # .env, random secrets, console password to the keychain
./scripts/generate-x509.sh      # cloud CA, certificates, bundles, CRL
./scripts/make-go-runtime.sh    # runtime-go/*.json, security/bundles-go
./v530/build.sh                 # images (v530/build-results.tsv, v530/build-logs/)
./v530/deploy.sh up             # bootstrap order, identities, policies (idempotent)
```

`./v530/deploy.sh down` removes the containers and keeps volumes, secrets and certificates.

Do not use `make up`: the Makefile was copied from the 5.2 GoCloud and its build targets expect the 5.2 source layout.
Its helper targets still apply, for example `make console-password`, `make smoke-security` and the
`configure-*-policy` targets.

## Console

Open http://gocloud-v53.localhost:7490/ and log in with the console password (`make console-password` prints it).
The console is the primary LocalCloudManager-go behind an nginx proxy that holds its own client certificate; other
host names are redirected to `gocloud-v53.localhost`.

## Tests

```sh
./scripts/smoke-test.sh               # 13 checks
SMOKE_ALL=1 ./scripts/smoke-test.sh   # 19 checks, optional systems included
./scripts/smoke-security.sh           # security regression, 130 checks
```

Results of the recorded deployment (2026-11-11) are in `v530/README.md`; the logs are `v530/smoke-*.log`.

## Layout

| Path | Content |
|---|---|
| `compose.yaml` | generated Compose definition (`compose.yaml.before-*` are earlier versions) |
| `v530/` | this deployment: `generate.py`, `build.sh`, `deploy.sh`, the console launcher and proxy, the health-probe image layer, build and test logs |
| `scripts/` | secrets, PKI, identity provisioning, ConsumerAuthorization policies, smoke tests |
| `runtime-go/` | one JSON configuration per Go system, written by `scripts/make-go-runtime.sh` |
| `runtime/` | `ServiceRegistry-go/application.properties` is mounted into the ServiceRegistry; the other folders came with the 5.2 cloud and are not referenced by `compose.yaml` |
| `amqp/`, `mqtt/` | broker configuration and ACLs |
| `security/*.ext` | certificate extension files used by `scripts/generate-x509.sh` |
| `ARROWHEAD-NAMING.md` | naming of systems, services and certificates |
